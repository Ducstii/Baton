# Baton

[![CI](https://github.com/Ducstii/Baton/actions/workflows/ci.yml/badge.svg)](https://github.com/Ducstii/Baton/actions/workflows/ci.yml)

Multi-agent orchestration tool

Diagnose problems, dispatch parallel fixers in isolated git worktrees, review every fix, and report results.
